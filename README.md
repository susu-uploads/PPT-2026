## Практические работы

Каждая практика соответствует одному заданию LMS. Реализованные практики №1–7 — самостоятельные CMake-проекты без тестовой обвязки. Проверка выполняется компиляцией и прямым запуском программ. Программы с параметрами принимают полный набор позиционных аргументов либо читают те же значения через stdin без аргументов запуска; получение параметров находится в main, выполнение — в run.
